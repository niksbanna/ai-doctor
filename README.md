# AI Doctor - General Physician Assistant

A comprehensive AI-powered medical assistant that acts as a general physician assistant. The system collects symptoms and medical history, identifies red flags, generates differential diagnoses with confidence scores, recommends investigations, provides safe preliminary management, checks medication safety, explains reasoning, cites evidence, escalates emergencies, and always includes "Clinician verification required" disclaimer.

## 🚨 Important Medical Disclaimer

**⚠️ CLINICIAN VERIFICATION REQUIRED**

This AI system is designed to ASSIST healthcare professionals, not replace them. All assessments generated by this system MUST be reviewed and verified by a qualified healthcare professional before any clinical decision-making or treatment. This system:

- Is NOT a substitute for professional medical advice, diagnosis, or treatment
- Should NOT be used for emergency medical situations (call 911 immediately)
- Requires validation by licensed healthcare providers
- May contain errors or incomplete information
- Does not establish a doctor-patient relationship

## Architecture

The system combines two complementary approaches:

1. **Rule-Based Safety Layer**: Deterministic checks for red flags, vital signs, medication interactions
2. **LLM Reasoning Layer**: AI-enhanced differential diagnosis and clinical reasoning (optional)

This dual approach ensures that critical safety checks are always performed regardless of AI model availability or performance.

## Quick Start

### Basic Usage

```python
from ai_doctor import PhysicianAssistant, PatientInput
from ai_doctor.models import Symptom, MedicalHistory, Severity

# Create patient input
patient = PatientInput(
    patient_id="ANON-001",
    age=35,
    sex="F",
    chief_complaint="Runny nose and cough for 3 days",
    symptoms=[
        Symptom(
            name="Runny nose",
            duration="3 days",
            severity=Severity.MILD
        ),
        Symptom(
            name="Cough",
            duration="3 days",
            severity=Severity.MILD
        )
    ],
    medical_history=MedicalHistory()
)

# Initialize assistant
assistant = PhysicianAssistant()

# Perform assessment
assessment = assistant.assess_patient(patient)

# View summary
print(assessment.summary)

# Get structured JSON output
json_output = assistant.to_json(assessment)
print(json_output)
```

## Usage Examples

### Example 1: Common Cold Assessment

```python
from ai_doctor import PhysicianAssistant, PatientInput
from ai_doctor.models import Symptom, Severity

patient = PatientInput(
    age=28,
    sex="M",
    chief_complaint="Cold symptoms",
    symptoms=[
        Symptom(name="Runny nose", duration="2 days", severity=Severity.MILD),
        Symptom(name="Cough", duration="2 days", severity=Severity.MILD),
        Symptom(name="Sore throat", duration="1 day", severity=Severity.MILD)
    ]
)

assistant = PhysicianAssistant()
assessment = assistant.assess_patient(patient)

# Output includes:
# - Differential diagnosis: Viral URI (70% confidence, ICD-10: J06.9)
# - Management: Supportive care, fluids, rest
# - Urgency: Routine
# - Clinician verification required disclaimer
```

## API Reference

### PhysicianAssistant

Main class for performing medical assessments.

```python
assistant = PhysicianAssistant(api_key=None, model="gpt-4")
```

**Parameters:**
- `api_key` (optional): OpenAI API key for enhanced reasoning
- `model` (optional): Model to use (default: "gpt-4")

**Methods:**

- `assess_patient(patient_input: PatientInput) -> MedicalAssessment`
  - Performs comprehensive patient assessment
  
- `to_json(assessment: MedicalAssessment) -> str`
  - Converts assessment to JSON string
  
- `to_dict(assessment: MedicalAssessment) -> Dict`
  - Converts assessment to dictionary

### PatientInput

Patient data model.

```python
PatientInput(
    patient_id: Optional[str] = None,
    age: int,
    sex: str,  # M/F/Male/Female/Other/Unknown
    chief_complaint: str,
    symptoms: List[Symptom],
    medical_history: MedicalHistory = MedicalHistory(),
    vital_signs: Optional[Dict[str, Any]] = None

```

## Safety Features

### Rule-Based Safety Checks

The system includes comprehensive rule-based safety checks that operate independently of AI reasoning:

1. **Emergency Symptom Detection**
   - Chest pain, stroke symptoms, severe bleeding
   - Difficulty breathing, loss of consciousness
   - Suicidal ideation

2. **Vital Signs Monitoring**
   - Temperature >103°F or >39.4°C
   - Blood pressure: Systolic >180 or <90
   - Heart rate: >120 or <50
   - Oxygen saturation <90%

3. **High-Risk Patient Factors**
   - Immunocompromised conditions
   - Cancer, HIV/AIDS
   - Organ transplant recipients

4. **Medication Interactions**
   - Anticoagulant interactions
   - High-risk medication warnings
   - Age-specific considerations

5. **Age-Specific Checks**
   - Fever in infants <2 years
   - Falls in elderly >65 years

### Medication Safety

All medication recommendations undergo safety screening:
- Allergy checking
- Drug-drug interaction detection
- Contraindication assessment
- Age-appropriate warnings
